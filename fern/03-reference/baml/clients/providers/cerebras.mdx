[Cerebras](https://www.cerebras.ai/) supports the OpenAI client, allowing you to use the
[`openai-generic`](/docs/snippets/clients/providers/openai) provider with an
overridden `base_url`.

See https://inference-docs.cerebras.ai/resources/openai for more information.

```baml BAML
client<llm> MyClient {
  provider openai-generic
  options {
    base_url "https://api.cerebras.ai/v1"
    api_key env.CEREBRAS_API_KEY
    model "llama3-70b-8192"
  }
}
```
